matrix-cat

Authentic green digital rain terminal simulator with half-width Katakana, in-place mutations, 24-bit Truecolor gradients, and zero terminal leaks.

View on GitHub Homebrew Tap

Installation via Homebrew

Install directly via Homebrew using the official tap:

brew install smford/tap/mcat

Or tap first, then install:

brew tap smford/tap && brew install mcat
mcat — terminal session

$ mcat -color green -fps 60 -density 70

// Rain streaming... Press 'c' to cycle themes, Space to pause, 'q' to exit

Engine Architecture & Reliability

🛡️ Zero Terminal Glitches
Restores raw mode, alternate screen buffer, and cursor visibility on SIGINT, SIGTERM, or panics.
⚡ Ultra-Low Resource Usage
ANSI color escape deduplication and single-buffer batch writes reduce I/O by >80%.
📐 Dynamic Window Resizing
Traps POSIX SIGWINCH signals to adapt columns instantaneously to window changes.
🎨 Authentic Movie Glyph Engine
Half-width Katakana (`ｦ-ﾝ`), in-place cascade mutations, and 6 vibrant Truecolor presets.

Interactive Keyboard Controls

Key Action
q / Esc / Ctrl+C Exit cleanly and restore terminal
Space Pause / Resume rain animation
c Cycle palettes (Green, Cyan, Amber, Red, White, Rainbow)
+ / - Increase or decrease drop density
r Reset and re-spawn all rain streams
